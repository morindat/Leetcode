# Leetcode

My C++ solutions to LeetCode problems — around 228 files, covering the core patterns.

## Topics covered

- Arrays, strings and two pointers
- Binary trees and binary search trees
- Graphs — BFS, DFS, topological sort, union-find
- Dynamic programming
- Heaps, stacks and queues
- Backtracking and greedy
- Design problems (e.g. `LRUCache`, `KthElementFromStream`)

## Conventions

One file per problem, named after the problem in camel case — for example
`bestTimeToBuyAndSellStock.cpp`.

## Build

Compile any single file:

```sh
g++ -std=c++17 -O2 path/to/problem.cpp -o out
./out
```
